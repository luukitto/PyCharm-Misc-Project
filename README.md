# RAG chatbot with Ollama LLM

This repository is a personal workspace that contains:
- `ChatBot/ollama_pdf_rag/`: a local PDF RAG app using Ollama, LangChain, and Streamlit.
- `insurance.csv`: a sample dataset used in notebooks.
- `notebook.ipynb`, `notebook1.ipynb`, `Untitled.ipynb`: exploratory notebooks.

## Getting started

1. Create and activate a virtual environment.
2. Install the app dependencies:
   ```bash
   pip install -r ChatBot/ollama_pdf_rag/requirements.txt
   ```
3. Run the Streamlit app:
   ```bash
   python ChatBot/ollama_pdf_rag/run.py
   ```

For full documentation and usage details, see `ChatBot/ollama_pdf_rag/README.md`.
